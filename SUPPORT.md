# Support & feedback

Use this repository's [Issues](https://github.com/rmncld/MakerDeck/issues) for questions, reproducible bugs and feature requests.

For a bug report, include:

1. MakerDeck, Stream Deck and Windows versions.
2. The action involved and the steps that reproduce the issue.
3. What you expected and what actually happened.
4. Whether the project is linked for development or installed from a package.
5. Relevant terminal output or screenshots, with private information removed.

Do not post credentials, access tokens, private source code or unredacted personal paths. Plugin Check reports and logs can contain local paths and project information; review them before sharing.

For a feature request, describe the workflow you want to improve and how the proposed action would help.

This is a presentation and support repository, not the MakerDeck source repository. Please do not upload plugin binaries or copies of the commercial package here.
